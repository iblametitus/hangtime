# Gym Buddy

> Placeholder README. The full English README for the hackathon submission is written in milestone M8 (see `docs/PLAN.md`).

**Goal:** A smarter training partner. Send it an exercise video and it tells you whether the exercise is backed by evidence, whether it fits your goals, and which exercise in your next session to swap it for without breaking your plan.

**Users:** Ambitious basketball players and athletes working on jump height and athleticism; coaches.

**Core feature:** Three-step answer for every exercise: evidence verdict with verified citations, personal fit, deterministic swap proposal with converted volume.

**Stack:** Python 3.12, FastAPI, HTMX, SQLite, NVIDIA Nemotron models via Nebius Token Factory, Tavily, deployed on Nebius Serverless Endpoints.

**Definition of done:** Live demo URL, public repo with MIT license, demo video under 3 minutes, submission on Devpost by Oct 30, 2026.

Built for the [Nebius x NVIDIA Global AI Hackathon](https://nebiusglobalaihackathon.devpost.com/), track "Best Apps & Agents".
